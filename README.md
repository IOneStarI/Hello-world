# Overview

This is my "Hello World" web project, made to demonstrate foundational web development skills by combining HTML, CSS, and JavaScript.

## Project Description

 "Hello World" website featuring:
- Live clock displaying the current time
- Fully responsive design that works on all devices
- Hosted on GitHub Pages for easy deployment

## Purpose

My goal is to:
- Master the fundamentals of HTML, CSS, and JavaScript
- Learn modern web design principles and best practices
